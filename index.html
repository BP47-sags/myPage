飲料訂購網站

這段程式碼實現了一個具備現代感且功能完整的「飲料訂購系統」。它採用 Bootstrap 5 結合 jQuery，具備實時總價計算與表單驗證功能。外觀上使用了漸層標題、玻璃擬態（Glassmorphism）卡片以及動態浮動圖示，提供優質的 UI/UX 體驗。使用者提交後，網頁會即時渲染美化的訂購明細，非常適合作為前端互動開發的實務範例。

Youbike站點資訊

這段程式碼實現了 台北市 YouBike 2.0 即時資訊系統。透過 jQuery AJAX 技術串接政府 Open Data，將 JSON 資料動態渲染至網頁。功能亮點包含：RWD 響應式表格設計、自動判斷「無車可借」以紅字警示，以及針對「停用站點」自動加上刪除線與標記，是典型的資料驅動型網頁實作範例。

飯店查詢網站

這段程式碼實現了互動式飯店檢索系統。結合 AJAX 讀取縣市與飯店 JSON 資料，具備動態聯動選單、關鍵字過濾與自動分頁功能。視覺上除了使用 Bootstrap 5 卡片呈現外，更整合了 D3.js 文字雲與 SweetAlert2 互動視窗，讓使用者能透過視覺化熱詞快速搜尋，是集合資料清洗、UI 渲染與多項外掛套件應用的進階實務作品。
